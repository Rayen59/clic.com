# MK: THE LAST EMPIRE

**An original open-world crime mystery — playable web prototype**

> One city. Hundreds of secrets. A thousand ways to survive.

## Current build: Prototype 0.1 — Ashes of Meridian

A browser-based 3D vertical slice built with Three.js. It establishes the visual direction and the first gameplay loop for a much larger original crime saga.

### Play
Open index.html in a modern browser with internet access. Three.js is loaded from jsDelivr. For local development, run a static server in this folder (for example: python -m http.server 8000), then visit http://localhost:8000.

### Controls
- WASD — move / drive
- E — interact, talk, enter or exit a vehicle
- Shift — sprint
- Space — reserved for braking while driving
- Mobile — on-screen directional and action buttons

### Prototype features
- 3D city blockout with roads, buildings, trees and street props
- Third-person player character
- Drivable vehicles
- Ambient pedestrians
- Police pursuit and wanted level
- Health, cash and basic arrest loop
- Story objectives, dialogue prompts and an evidence clue
- Responsive HUD and mobile touch controls

### Story premise
In Meridian City, former getaway driver Alex Mercer returns after his brother Elias vanishes. A trail of coded evidence points toward a private security empire, a corrupt police unit, and a secret buried beneath the old docks. Choices will shape alliances and the city's future.

### Planned development roadmap
1. Foundation: world streaming, collision, save/load, audio, settings and input abstraction.
2. People: named cast, dialogue trees, schedules, relationships, faction reputation and branching missions.
3. City: distinct districts, interiors, traffic AI, pedestrians with routines, shops, garages and safehouses.
4. Systems: wanted-level escalation, police search tactics, evidence, stealth, combat, vehicle damage and economy.
5. Mystery: multi-stage ciphers, environmental clues, logic cases and optional investigations with persistent consequences.
6. Campaign: chapter-based story, side stories, endings and post-game activities.

### Scope note
This is an early playable prototype, not a finished AAA-scale game. The current city uses placeholder geometry and the story is a vertical slice. The roadmap describes future work; those systems are not yet implemented.
